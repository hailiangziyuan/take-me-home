# Security and Safety Policy

## Scope

This project is a local-first self-practice Android app. It is not a therapy, diagnosis, crisis response, or medical service.

## Report a Security Issue

Please open a GitHub issue for non-sensitive bugs. For sensitive security issues, contact the maintainer privately when a private channel is available.

Do not include private journal entries, personal trauma details, audio samples, or identifiable information in public issues.

## Safety Expectations

Contributions should preserve these boundaries:

- no medical or clinical claims
- no crisis-chatbot behavior
- no hidden network calls
- no default data upload
- no third-party audio or media without a license
- no public storage of private practice records

If a user may be at risk of self-harm, harming others, or losing behavioral control, the app should direct them to trusted people, local emergency services, or qualified professionals.
