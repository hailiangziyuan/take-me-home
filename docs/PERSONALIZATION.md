# Personalization Workflow

带我回家的长期目标不是让所有人使用同一套练习脚本，而是提供一个安全、透明、本地优先的开源核心，让每个人可以在私密环境中生成适合自己的练习 App。

## Core Idea

1. 用户先进行充分的自我探索。
2. 用户可以和可信 AI 工具、专业人士或受过训练的陪伴者讨论自己的困扰模式。
3. 用户把探索结果整理成抽象主题，而不是公开的私人故事。
4. 用户在本地副本或私有仓库中生成自己的练习脚本。
5. App 在本地运行，记录也保存在本地。

公共仓库只维护通用框架、安全边界、隐私原则和非个人化模板。

## What Must Stay Private

不要把这些内容提交到公共仓库：

- 真实姓名、联系方式、家庭成员、工作单位、学校或可识别人物
- 具体创伤经历、性经历、关系细节或未公开疾病信息
- 练习记录、日记、语音样本或私人配音
- 和 AI 或咨询师对话的原文
- 任何可能让他人识别用户身份的细节

## Safe Public Abstractions

可以公开讨论的是抽象主题，例如：

- 被拒绝后的羞耻感
- 过度讨好
- 边界困难
- 焦虑和睡眠压力
- 对亲密关系的不安全感
- 工作压力下的自我否定

公开模板应该使用虚构人物、合成案例或高度概括的主题。

## Personal Script Shape

一个私有脚本可以保留相同的 25 分钟结构：

| Time | Stage | Goal |
| --- | --- | --- |
| 0:00-3:00 | Grounding | 回到身体和呼吸 |
| 3:00-8:00 | Observation | 看见今天的情绪和冲动 |
| 8:00-15:00 | Self-compassion | 安抚受伤的内在部分 |
| 15:00-22:00 | Reframing | 改写核心信念 |
| 22:00-25:00 | Commitment | 选择一个很小的行动 |

真正个性化的是每一段的语言、触发主题、核心信念和行动承诺。

## Safety Boundaries

个性化脚本不能替代专业心理咨询、精神科诊疗或紧急服务。

如果用户出现强烈自伤、伤人冲动，或感觉无法控制行为，脚本应明确引导用户联系可信任的人、当地紧急服务或专业人员。
