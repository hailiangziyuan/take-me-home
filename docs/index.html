带我回家

一个本地优先的 Android 心理自助练习 App，把温和的 25 分钟练习变成可执行、可记录、可坚持的日课。

查看 GitHub 隐私说明

公益核心

  • 身体落地、正念观察、内在安抚、信念重构、今日行动承诺
  • Android TTS 本地朗读，不依赖云服务
  • Room 本地记录，DataStore 本地设置
  • 不需要账号，不上传隐私数据

安全边界

这个 App 是自我练习辅助工具，不替代心理咨询、精神科诊疗或紧急求助。如果出现强烈自伤、伤人冲动，或无法控制行为，请立即联系身边可信任的人、专业人员或当地紧急服务。

可持续方向

开源仓库提供通用工具和安全边界。未来可以围绕个性化脚本审核、授权音频包、机构部署和专业陪伴流程建立可持续服务。
