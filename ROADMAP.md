# Roadmap

## 0.1 Public MVP

- [x] Local-first Android practice flow
- [x] 25-minute staged guidance
- [x] Android TextToSpeech fallback
- [x] Local practice history with Room
- [x] Local settings with DataStore
- [x] First-use safety notice
- [x] Public README, privacy, security, and contribution guidelines

## 0.2 Safety and Trust

- [ ] Add a script safety review checklist
- [ ] Add accessibility review for all screens
- [ ] Add a clearer local data deletion confirmation
- [ ] Add optional export/import with explicit user consent
- [ ] Add tests for streak calculation and record storage

## 0.3 Community Templates

- [ ] Add generic practice script templates
- [ ] Add translation-ready string resources
- [ ] Add English README
- [ ] Add contributor guide for licensed audio packs

## 0.4 Personalization Workflow

- [ ] Add a safe personalization guide
- [ ] Add a private script template format
- [ ] Add checks that prevent private scripts from being committed by accident
- [ ] Add examples using fictional, non-identifiable personas only
- [ ] Explore a local-only generator for creating private practice variants

## Long-Term Direction

The public core should remain local-first and privacy-preserving. Future personalization should be opt-in, transparent, and reviewed against safety boundaries before it is used with real users.
